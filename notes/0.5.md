# 上岸 0.5 · 搜索能搜解析了，批改结果留下来了

这次只做两件实事：把「搜索」从半成品补成能用的工具，把「申论/综应批改」从一次性输出变成能回看的记录。

## 0.5.0

### 搜索：题干 + 解析一起搜

以前只搜题干。可复习时想找的往往是「哪道题讲过这个说法」——那句话在解析里，搜不到。

- 题干和解析**同时**参与匹配，结果分「题干命中」「解析命中」两类标签
- 解析命中时直接给摘要片段，关键词**高亮**
- 按命中位置排序：题干命中的排在只命中解析的前面
- 顶部四个筛选：全库 / 只看当前科目 / 近 3 年 / 近 5 年
- 单次最多 80 条（原 50），点开即做题
- 顺手修掉一个老 bug：搜索结果点开时把 id 转成数字，非数字 id 会变成 `NaN` 打不开

### 批改：结果落库，能回看、能看趋势

以前批改完就没了——关掉页面再想看，只能重批一遍。

- 批改成功后自动存档（IndexedDB `essays`，完全离线）
- 回顾 → **批改** 新 tab：已批改篇数、平均分、最高分、最近一次 vs 第一次
- 分数趋势条：每篇一根，高低就是得分率
- 点任意一条回看**我的作答**和**完整批改意见**
- 旧数据不受影响（数据库版本 3 → 4，只新增一个 store）

## 0.5.1

### 检查更新老是「查不出来」——修了

GitHub 在墙外，`raw.githubusercontent.com` 时通时不通，公共反代也会 502。不换仓库托管也能扛：

- manifest 源从 3 个扩到 **7 个**：gh-proxy、ghfast、ghproxy.net、raw.gitmirror、raw 直连、jsDelivr、fastly.jsDelivr
- 分两波跑：第一波只跑**无缓存**的反代/直连（8 秒），全挂了才跑 CDN（5 秒）兜底
  - 原因：jsDelivr 的 `@main` 有 12 小时缓存，一起赛跑它最快，拿到的却是半天前的清单，会误判「已是最新」
- 谁先回用谁：以前要等所有慢源一起超时（最长 12 秒），现在 1 秒内就能出结果
- **本机缓存兜底**：成功拿到清单就存一份；七个源全挂（或干脆没联网）时用它，照样能看出有没有新版本、并从清单里的地址下载
- 弹层底部显示**清单来源**（加速镜像 / 镜像 gitmirror / 直连 GitHub / jsDelivr / 本机缓存）和缓存年龄，排查问题不用猜
- 一次失败会自动再试一次（换新时间戳，避开临时抽风）
- 时政清单同样换成多源

## 0.5.3

### 进度条「丢了」的真正原因

上一版把进度条画粗了，但用户反馈的「没进度条」其实是另一个 bug：

- 后台正在下题库或新版 App 时，只要**再点一次「检查更新」**（或者把弹层关掉又打开），前端都会先调一次原生 `reset()`。
- `reset()` 无条件把状态清成 `idle / 0%`，而后台线程还在跑，`start()` 一看「已有任务正在跑」就直接返回。
- 结果：**弹层显示 0% 空条（或一句「已有更新任务在进行」），通知栏的下载进度却是正常的**。

修法：

- 原生 `reset()`：任务还在跑（`worker.isAlive()`）或 App 包正在下载时**不清状态**，直接返回。
- 原生 `status()`：后台有任务在跑但状态是 `idle` 时，如实报成 `downloading`，并新增 `running` 字段。
- 前端 `checkUpdate()`：先问一次状态，`running && downloading/checking` 就**不再 reset、不再重启任务**，直接接着显示当前进度。

实测：下到 2% 时关掉弹层再打开，弹层显示「正在下载 13% · 4.0 MB / 30.2 MB」，进度条继续走。

## 0.5.4

### 判断题、多选题：从「不能做」到「能做」

盘题库时发现两处「题在库里，但根本做不了」：

- **判断题 4,115 道**（公基 3,655）在库里没有选项文本，答案存成 A/B。App 一律按「没有选项 = 主观题」处理，于是判断题被渲染成 **AI 批改框**——写一段话，就被按申论口径打分。
  现在按 `type=5` 补上「正确 / 错误」两个选项，题型标签也改成「判断题」；判分走 `answerIndex`，不再 `Number('B')` 得到 NaN 把每道判断题都判成错。
- **多选题 3,662 道** `answerIndex` 是 -1，正确答案存在 `answer` 里（形如 `0,1,3`）。旧的点选逻辑是单选，点了第二个会把第一个取消，多选题**永远只能选一个**。
  现在多选题可以连点多个（再点一下取消），确认后整组比对，反馈里显示「正确答案 AB · 你的选择 AC」，选项上分别标绿和标红。

这两类题合计 7,777 道，占题库 5.4%。
