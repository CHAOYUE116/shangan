# 上岸 0.9

这一版的主线只有两句：**让题真的能做，让界面真的点得动。**

15.2 万道题，331 MB 一次装好，离线可用。下面按「你会感觉到什么」来写，技术细节在 `CHANGELOG.md`。

---

## 一、题终于能做了：材料、填空、空壳题

### 材料题的表格，全回来了

之前整卷模考里的资料分析题只剩一句提问和四个选项 —— 表呢？表在库里，取题的时候没取出来。三条路（整卷、测评、练习）的取题语句都没带 `material` 这一列，取到前端就成空的了。

现在补上了，顺带修了「取到又被覆盖成空」的第二处。样板：一套 120 题的整卷里 50 道带材料，表格、图、长材料都在。

### 填空题的横线，能看见了

有些题的空在原文里就是一个半角空格（`<u> </u>`），渲染出来只有几个像素，等于没画。现在的空是一段 3.2em 的下划线，扫一眼就知道空在哪。

### 1,382 道「空壳」资料分析题，不再出现

有些资料分析题，材料表没跟着存下来、题干本身又不含数据（典型是「2003-2011 年，我国财政收入占 GDP 比重最大的一年是」四个年份当选项）。这批题在粉笔那边已经下架，材料补不回来。

新增一条判定（资料分析 + 无材料 + 题干无图 + 题干 < 60 字），1,382 道全部拦掉，练习、考试、每日任务都不会再抽到。题库里现在有 149,943 道可做题，坏题率 1.34%。

## 二、能力画像和基础测评，合成一个

以前是两套东西：一套是 36 题测评出的画像，一套是刷题记录算的正确率，看的人一头雾水。

现在只有一个账本：**首次测评只是往账本里填第一批数据**（每模块按 6 题计权），之后你每天刷的题继续累加，首测的权重随做题量一起衰减：

```
模块正确率 = (6 × 首测 + 之后做对) / (6 + 之后做题)
```

- 没做过首测：刷满 20 题、覆盖 3 个模块，就直接看六维图（标「粗判」）
- 样本不够：告诉你还差多少（「现在 4 道、覆盖 1 个模块」），可以去做首测
- 学习统计的估分、雷达、模块表、「最该补」，全部走这一套数

点「看画像」也不再偷偷开考了 —— 先说明这是啥、要多久、不做也能用，再让你选。

## 三、学习报告，重做成了周报

以前报告页和统计页长得几乎一样。现在分工明确：**统计看画像，报告看结论和下一步。**

报告页从上到下：

1. 一句结论 + 一句诊断（「进入提分期，正确率 50%，这个分段最值钱的是错题」）
2. 跟上周比：做题 / 正确率 / 活跃天数三列，带上周原始值
3. 这一周的节奏：七天柱状、达标日加深，最猛的一天、中位用时
4. 模块在往哪走：每个模块本周 vs 上周，±pt 标色
5. 这一周的考点：最稳的一个、最弱的两个
6. 下周做三件事：补最弱 / 清错题 / 今日目标，每条带按钮直达

配套新增一个接口 `GET /api/records/weekly`，一次算完上面所有数。

## 五、点得动了

| 改了什么 | 之前 | 现在 |
|---|---|---|
| 改设置、展开折叠 | 整页重绘、跳回顶部 | 原地更新，滚动位置不动（实测 520px → 520px） |
| 首页「模考」→ 返回 | 回到考试 tab | 回到首页 |
| 我的 → 报告 → 统计 → 返回 | 再返回就卡住 | 报告 → 我的，一路退得出 |
| 首页两个「复习 4 道」卡片 | 重复 | 只留一张 |
| 「最弱的一块」和「今日重点」 | 说同一个模块 | 今日重点避开最弱那个 |
| 错题本 | 组合外的 34 道被藏起来 | 全列出来，只加一句说明 |

题库页底部恢复了**自定义刷题**：科目 / 题量（10·20·30·50）/ 难度 / 年份，底部一句话说清会抽什么。考试页那个入口改回叫**基础测评**（做完才出六维画像），结果页仍叫能力画像。
