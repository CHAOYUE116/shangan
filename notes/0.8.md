# 上岸 0.8 · 学习统计会自己给方案了

这一版的重点只有一个：**学习统计从「给你看数字」变成「告诉你先补哪、今天练什么」**。

其余是这半个多月攒下来的题库与界面修正，一并放出。

---

## 一、AI 学情分析（新）

打开「我的 → 学习统计」，在能力分析下面多了一张卡片。

点「分析一下」，App 会把你这段时间的**做题数据打包成一份统计摘要**（不传任何题目正文、不传答案、不传你的笔记），交给你自己配置的 AI，换回一份有结论、有依据、能直接开练的方案。

出来的东西是六段：

| 段落 | 内容 |
| --- | --- |
| 一句话结论 | 你现在的问题在哪，不是「基础不牢」这种废话 |
| 六维评分 | 知识覆盖 / 正确率 / 解题速度 / 稳定度 / 记忆保持 / 坚持度 |
| 诊断 | 3–4 条，每条都带数字依据，标「影响高/中/低」 |
| 根因 | 现象 → 原因 → 常见误区 |
| 这周怎么练 | 本周目标 + 每天 3–4 个动作（几分钟、练什么）+ 验收标准 |
| 配好的训练 | 三个按钮，点一下直接进入对应练习 |

**喂给 AI 的是什么**：近 21 天的整体数据、六个模块各自的正确率 / 中位用时 / P90 用时 / 三档难度正确率、最弱与最强章节、易中难分布、题型分布、每日题量曲线、秒选占比、错题重复率、二次答对率，再加你的考试日期与每日目标。**只发数字，不发内容。**

**四条硬约束**（在提示词层面就锁死，返回后还会再校验一遍）：

1. 只准用数据里出现的数字，引用不到数字的结论直接丢弃；
2. 「去练」的目标只能是数据里真实存在的模块或章节，编造的名字会被删掉；
3. 样本少于 100 题时，置信度最高只能给「中」；
4. 必须先诊断再开药，不允许只给励志话。

**成本**：一次约 4k 输入 + 1k 输出，DeepSeek 上大约 0.002 元。结果缓存在本机，重新分析才会再请求。

**输出长度**：这一版的输出上限给到 5000 tokens（推理模型的思维链也算在里面），AI 设置里的默认值改成 6000，避免 JSON 被截断后提示「返回内容不完整」。

**边界**：卡片底部有一行固定的免责声明 —— AI 分析仅供参考，结论可能出错，不构成备考建议，以真题与官方考纲为准。

没有配 AI Key 也能用 App —— 这张卡会显示「去填 Key」，其余功能不受影响。

## 二、学习统计与学习报告分工

以前两页内容像双胞胎，现在分开：

- **学习统计**＝数据面板：时间范围（7 天 / 30 天 / 全部）、估分环、六维能力图（我的 vs 目标）、模块正确率（带目标刻线）、近 7 天趋势，外加新的 AI 学情分析。
- **学习报告**＝结论与行动：本周处在哪个阶段、跟上周比怎样、这周做三件事（每条带按钮直达）。

顺手修了一个一直没生效的毛病：统计页顶部的「近 7 天 / 近 30 天 / 全部」以前点了没反应，现在真的会切换。

## 三、题库：10.3 万 → 15.6 万道

这轮把粉笔的题号空间扫了一遍（纯只读接口，不消耗练习额度），补进来 5.3 万道题，都是带解析、带考点、带官方难度的。

| 科目 | 题量 | 解析覆盖 |
| --- | --- | --- |
| 公务员·行测 | 46,710 | 99.9% |
| 事业编·职测 | 64,693 | 99.8% |
| 事业编·公基 | 37,786 | 98% |
| 公务员·申论 | 4,286 | — |
| 事业编·综应 | 2,825 | 99% |
| **合计** | **156,282** | **97.8%** |

同时收进来的还有：

- **官方难度**：14.2 万道题拿到了粉笔自己的难度值（1–9），覆盖 97% 的客观题。之前的难度是我们按题型和章节估的，现在换成了真值 —— 实测官方难度与真实正确率的相关系数 −0.28，我们原来的估算只有 −0.03（基本等于没信息）。
- **全站正确率**：4.8 万道题拿到了粉笔全站作答的正确率，用来把题目分成易 / 中 / 难三档，每日任务按档抽题。
- **做不了的题先藏起来**：缺材料、图丢了、解析公式被吞、答案与解析打架、平台打码的题，统一打标后在出题时过滤。现在这类题占 **0.21%**（0.6.5 时是 2.07%）。

## 四、界面与细节

- 题库页的「错题再练 / 随堂测 / 随机 20 题」换成矢量图标，三张卡片居中，底部多余的「练 › 测 ›」删掉。
- 综应的分类完全按粉笔的结构来：案例分析题（单一题 / 综合题）→ 公文写作题（九类）→ 材料作文题，B/C/D 类岗位题型单列一组；二级可以再展开到具体考点，点进去就直接开练。
- 申论也按归纳概括 / 综合分析 / 提出对策 / 贯彻执行 / 文章写作分了组。
- 引导页改成五步：考试类型 → 省份 → 目标与节奏 → 接一个 AI（可选，内置技能也挪到这里） → 基础测评。默认选好事业编、浙江，少点几下。
- 筛选试卷时「联考 / 统考 / 浙江」排在前面，同名的重复卷去掉了。
- AI 解析的等待动画不再把文字挤到右边。

## 五、安装与已知边界

- 包名 `com.kaogong.shangan`，体积 **238 MB**，装完首次启动要拷 780 MB 题库，约 60–90 秒，属正常。
- 题库只发全量包（增量包带不动新加的难度列与考点表），所以升级会重新下一次。
- 建练习类采集（试卷整卷导入）目前被粉笔按账号限速，事业编还有 840 套职测卷、1,349 套公基卷在排队，后续版本补齐。
- AI 分析依赖你自己填的 Key 与网络；没有 Key 时相关入口会提示去设置，不影响刷题。
