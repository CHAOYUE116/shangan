# 上岸 0.4

这一版把「做题 → 交卷 → 复盘」这一圈补齐了：成绩单能下钻到考点、错题本能按模块筛、订正做对就自动移出，每题还会告诉你「你在这个考点的历史正确率」和「这道题的易错项」。另外把时政列表重新排过，加了序号和分割线。

## 0.4.3 — 时政正文按主题分段

- 点进一篇时政，正文不再是一整块文字：按原文的「1 / 2 / 3」切成一个个主题，每个主题带蓝色序号，主题之间一条分割线
- 标题头显示「10 个主题 · 4533 字」
- 列表页取消了逐条的月内序号（一个月一块卡 + 行间细线保留）

## 0.4.2 — 内置技能默认开启

- 第一次进 App 会把两套内置技能自动装好：**申论批改（shenlun-master）** 和 **花生十三技巧（gongkao-huasheng13）**，装在本地技能库里，配好 AI Key 就能直接挂到模型上
- 引导页最后一步能看到这个开关，不想用可以当场关掉；之后在「我的 → AI 助手 → 技能包」随时开关
- 技能内容随包内置，不联网也能装

## 0.4.1 — 时政列表

- 每个月的时政合成一张白卡，条与条之间一条分割线，左侧带月内序号
- 已读的整条置灰，顶部可以只看未读（`未读 N 篇`）
- 每条脚注「X 日 · N 字」+「练一练 3 题」

## 0.4.0 — 报告 / 错题 / 难度三件套

**成绩单下钻到考点**
- 模块得分下面挂考点标签（对 / 错 / 中性三色），点开能看每个考点的对错分布
- 逐题复盘时每题带考点名，「2 题 · 答对 0 · 0% · 2 个考点」这样的摘要行

**错题本**
- 顶部按模块筛选（只列出现 2 次以上的模块，最多 6 个）
- 「做对的题自动移出错题本」开关，默认开：订正对了当场移出，不再靠「累计 3 天做对」
- 错题总数改成「每题只认最近一次作答」，所以数字会比以前小——做对过的就不算了

**每题参照数据**
- 答完题的反馈条后面加一行：`考点 X · 你在这个考点正确率 62%（18 题）`
- 再加一句易错项：`易错项 B（你 2 次选了它）`
- 全站正确率这类数据粉笔不给，所以这里用的是**你自己的历史**，措辞也刻意写「你」而不是「全站」
