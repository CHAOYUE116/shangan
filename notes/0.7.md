# 上岸 0.7 · 把「自适应」真正接进刷题，题库按官方难度重排

0.6 到 0.7 只隔了三天，但改的是两件根上的事：**每天推给你的题，开始按你的能力水平挑难度**；**题库里 97% 的客观题有了官方难度和全站正确率**，我们之前自己估的难度被证明基本是噪声。

## 一、自学习引擎（原来只在实验室包里）

0.7.0 开始，引擎是正式功能，不用再装实验包。

### 账本是「章节级」的

你自己练出来的能力分，按**章节**记账（判断推理 / 言语 / 数量 / 资料 / 常识 / 政治理论，共 31 个章节），不是按 6,000 多个考点——因为单用户 500 条记录摊到 6,000 个考点上，每个考点不到 0.1 条，估不出任何东西。

- 每次作答都会更新该章节的能力分 θ 和不确定度 rd：`θ ← θ + K·(y − p)`，`K = 0.4·rd/(rd+0.5)`，`rd ← max(0.18, rd·0.985)`
- 答对答错的幅度由「这道题多难」和「蒙对概率」决定：`p = c + (1−c)·sigmoid(θ − b)`，单选 c=25%、判断 50%、多选约 10%
- 重装或换机后，从 `/api/records` 的历史作答回放一遍，账本自动重建

### 选题改成 ZPD（够得着的难度）

以前是「最弱考点 + 难度档」，现在是「预测正确率最接近 75% 的题优先」：

- 每次抽题先算每道题的 `p`，按 `|p − 0.75|` 升序，再加一点 Thompson 采样（`t + randn·min(1.5, rd)`）保证不总抽同一批
- 15% 的名额强制给「没怎么练过的章节」，避免一直困在最弱的那块
- 离线对照（12 个模拟学生 × 200 题，真实题库结构）：**学习增益比 0.6 的「只挑最弱」高 14.0%**；如果只挑最弱不加探索，反而比随机低 24%

### 每题难度也在学

除了章节能力，每道题自己也有一个难度估计 `b_q`：初始值取章节先验，答一次就往真实难度挪一点（`lr = 0.35/(1+n/8)`）。同一道题被反复做到时，这个估计会越来越准。

离线基准（`tools/lab-sim-qb.mjs`，AUC 用秩和法）：题库里随机抽、每题只遇一次时，每题难度没有收益（+0.00pt）；**题池 400 题反复练时 +0.88pt，题池 150 题时 +1.59pt**。也就是说：题池越小（越接近「考前只刷自己的错题」），每题难度越值钱。

### 复习档位也按引擎调了

固定档位 `1/2/4/7/15/30 天` 换成 `1/1/2/4/9/18 天`。离线模拟 60 个知识点 × 90 天：复习次数几乎不变（947 → 949 次），**保持率从 64.0% 提到 70.8%**。

## 二、题库质量：从「自己估难度」换成「官方难度 + 全站正确率」

这一轮找到两个只读接口，把之前补不动的四类问题一次性补齐（都不消耗「创建练习」额度）：

| 接口 | 给什么 | 规模 |
|---|---|---|
| `GET /api/{course}/questions?ids=` | 题干、材料、选项、答案、**官方难度 1–9** | 200 题/请求 |
| `GET /api/{course}/solutions?ids=` | 解析、考点、**全站正确率** | 30 题/请求 |
| `GET /combine/question/getMeta?requestKey=` | 整套练习的正确率 | 90–100 题/请求 |

结果：

- **官方难度覆盖 97% 客观题**（89,603 / 92,325 行），分布 `3:11,585 4:30,221 5:97,555 6:7,700 7:1,453`
- **难度确实可信了**：6,052 道同时有「官方难度」和「全站正确率」的题，两者相关系数 **r = −0.284**；而我们之前用题型/章节/题干长度估的结构先验，相关只有 **−0.033**（等于没有）。所以 `difficulty_est` 现在优先用官方难度重排，章节内按分位切成易/中/难三档，三档各 44% / 22% / 33%
- **材料「[object Object]」归零**：早期导入把材料对象字符串化了，2,408 道题的材料显示成一坨；这轮全部用官方 `material` 补回来（连同之前回填的 8,703 道，一共 13,561 道题的材料是新的）
- **解析回灌**：综应 +194、公基 +12,968、行测 +3,000、职测 +1,921，都是粉笔原文
- **公式图补到 60,735 张**（这一轮又补了 2,393 张），`images.db` 升级时也会跟着更新了（0.6.6 修的那个「图片库永不重拷」的坑）
- **坏题 1,347 → 134（0.13%）**。四类降幅：缺材料 65 → **0**、图丢了 394 → 16、解析公式被吞 673 → 82、答案与解析矛盾 213 → 35

顺手纠正了两个自己的误判：R3「公式被吞」原来会把「1271 年蒙古汗政权定国号为元」当成「…为元」判错（现在限制在数量/资料章节且要求数字紧跟单位）；R4「答案不符」208 道里 **201 道我们的答案和粉笔完全一致**，是解析串到了别的题上，已用粉笔解析整段替换，不是改答案。

## 四、修的毛病

- **题库打不开（0.6.6 的事故）**：`questions.chapter` 有 128 行 NULL，`mapChapterToNode()` 在 `ch.includes()` 上抛错，`/api/chapters` 挂掉 → 题库页永远转圈。现在 mapper 判空、NULL 章节按类别回填，题库加载失败也改成错误卡 + 重试按钮
- **返回失效**：从「学习报告 → 学习统计」再按返回，第一次能回报告，第二次回不去。原因是没记来源时直接用旧状态重渲染同一页；现在无来源时会先把「我的」子页和题库子页复位
- **设置页不再跳顶**：切外观/字号/开关原来会整页重绘（顺带 `scrollTo(0,0)`），现在只切当前项的高亮，滚动位置不动；顺便把「外观」「正文字号」的间距理顺
- **摸底考试**：抽题改成每个模块直接按易/中/难 2/3/1 抽 6 题（以前是抽 20 道再自己分桶，老库里 78% 的题都标 5，分不出来），并加了「正在抽题」的进度遮罩——本地库是同步调用，一个模块抽完让一帧，进度条才动得起来
- **图标**：补了 `cloud / download / sparkle / flag / target`，把原来重复用「灯泡」「软盘」的六处换掉（学习报告 → 旗、检查题库更新 → 云、检查 App 版本 → 下载、实验室 → 星芒、首页时政 → 靶心、首页模考 → 旗）
- **删掉 AI 刷题班入口**：那套四阶段计划已经被每日任务和智能组卷吸收，留着只会和主流程打架
