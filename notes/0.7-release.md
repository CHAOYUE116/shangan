# 上岸 0.7 · 题库补到十万道，学习引擎转正

0.7 是「上岸」的第一个大版本。它做三件事：把题库从「能用」补到「敢用」，把学习引擎从实验室转正，把学习数据拆成「看数据」和「看结论」两页。

---

## 一、题库：官方难度、官方正确率、逐条体检

**十万道题**（去重后），3,615 套试卷，60,735 张公式与图形图片，全部离线内置。

这一轮最大的变化不是数量，是**每道题的元数据终于可信了**：

- **官方难度**：以前「难度」是早期整卷数据填的默认值，八成都是 5，等于没有。现在 97% 的客观题拿到了粉笔的官方 1–9 档难度，并且用它重排了选题——「易/中/难」三档现在是真按难度分的。
- **全站正确率**：每道题带粉笔的全站正确率（5.8%–99.2%，均值 65%）。我们验证过：官方难度与真实正确率的相关系数是 **−0.28**，而此前自己按题型和章节猜的难度只有 **−0.03**（等于噪声）。这条数据是「按预测正确率出题」的基础。
- **解析全覆盖**：九万道客观题的解析、考点、正确率一次性补齐。答案与官方的一致率 **99.91%**——之前用户报的「答案和解析不符」，绝大多数其实是解析串到了别的题上，现在整段换成官方解析。
- **逐条体检**：每次采集完都过六道闸门（结构 / 图文 / 公式 / 答案一致性 / 内容打码 / 重复度），异常题写进 `q_bad` 列、出题侧统一过滤。**屏蔽不等于删除**——补齐后把标记改回去就恢复。

体检顺带救回了一批「看起来坏、其实能读」的题：比如解析里「进价为 [公式图]，而…」，公式图就在 HTML 里，只是纯文本列看不到。

**关于打码**：少数题（当前百级）的题干或选项里带 `****`，那是粉笔对未购课内容的遮挡，换账号取也一样。这类题现在被标为不可用，不会出现在练习里。

## 二、学习引擎：从「按最弱考点」到「按能力账本」

以前每日任务是「挑最弱的 3 个考点，70% 的题从这里出」。现在每个章节记一本账：

- **能力分 θ**：答对加分、答错减分，加减幅度由这条账的不确定度决定——第一次做错扣得多，做过几十题之后同样的错只微调
- **蒙对率 c**：四选一蒙对 25%、判断题 50%，不建这个参数的话「蒙对难题」会把能力分抬高，选题就会一直给你简单题
- **每题难度 b**：除了官方难度，还按你的实际作答校正（同一道题反复做，它的难度估计会朝你的表现靠）
- **遗忘衰减**：答对之后隔得越久，账本越不确定，复习优先级越高

出题时按「预测正确率落在 70%–80%」挑题（教育测量里的最近发展区），再留 15% 给没练过的章节做探索——只刷最弱的地方，会漏掉从没碰过的模块。

复习节奏也加密了：`1 / 1 / 2 / 4 / 9 / 18 天`。

**它到底有用吗**——我们用离线模拟 + 真实库结构量过：

| 场景 | 增益（相对「按最弱抽题」） |
| --- | --- |
| 题库全随机（每题只遇一次） | 0 |
| 题池 400 道反复练 | +0.9 pt AUC |
| 题池 150 道反复练 | +1.6 pt AUC |
| 题池 150 道 + 学生差异更大 | +1.9 pt AUC |
| 选题策略对照（模拟 12 人 × 200 题） | 学习增益 13.2 vs 11.6（+14%），且覆盖考点从 32 个升到 60+ |

结论是诚实的：**在同题反复练、题池不大的场景（也就是真实备考）里有效，全库乱刷时没差别**。

## 三、学习数据：统计看板 + 行动报告

以前「学习统计」和「学习报告」内容重叠，都是三张卡 + 柱状图 + 薄弱模块。现在拆成两页：

- **学习统计**（看数据）：估分环、六维能力雷达（我的 vs 目标）、模块正确率带目标刻线、近 7 天趋势，支持近 7 天 / 30 天 / 全部
- **学习报告**（看结论）：一句话诊断（这周还没开张 / 还在打底 / 进入提分期 / 节奏稳了）→ 跟上周比（做题 / 正确率 / 活跃天数）→ 这周做三件事（补最弱 · 清错题 · 今日目标），每条都带按钮直达

## 四、界面与体验

- **图标统一**：全站换成同一套线性矢量图标，去掉了重复和风格不一致的几个
- **设置页不再跳顶**：切换外观、字号、答题偏好都是原位更新，页面不会滚回顶部
- **返回链修好**：学习报告 → 学习统计 → 返回 → 再返回，现在能一层层退回去
- **摸考题**：抽题时给「正在抽题」进度条（36 题约 0.7 秒，主要是让等待有反馈）
- **AI 刷题班入口移除**：那套「四阶段备考计划」的算法已经融进每日任务，不再单列入口

## 五、安装与升级

- 首次安装：解压 660 MB 题库（约 1 分钟），只有一次
- 覆盖安装：如果题库版本没变，不会重拷；版本变了会自动更新（图片库这次也修了「升级后不更新」的问题）
- 从 0.6.x 升级：题库整体换代，会走一次全量下载

## 题库：15.6 万道

粉笔的题目 id 是连续可枚举的，而 `/api/{course}/questions?ids=`、`/api/{course}/solutions?ids=` 是纯 GET、批量、不占「创建练习」额度。于是扫了一遍 id 空间（1–490 万），把库里没有的题捞出来：

| | 之前 | 现在 |
| --- | ---: | ---: |
| 唯一题 | 103,257 | **156,282** |
| 行测 | 45,275 | 46,710 |
| 职测 | 30,490 | 64,675 |
| 公基 | 23,342 | 37,786 |
| 解析覆盖 | 93% | **97.8%** |
| 官方难度 | 0（自己估的） | **97%** |
| 坏题 | 1,347（1.3%） | **327（0.21%）** |

新扫进来的题按题目自带考点归到一级模块（24,954 道），公基题从职测卷搬到公基卷（12,255 道）。官方难度与真实正确率的相关系数是 −0.28，我们自己按章节估的是 −0.03——所以现在选题用的档位是粉笔的，不是猜的。
