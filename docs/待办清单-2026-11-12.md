## 二、引擎（本轮聊的重点）

### 已经做完的
- 调研报告：`docs/引擎算法调研-2026-11-12.md`（BKT/DKT/IRT/FSRS 各自需要多少数据、能不能做）
- 实验室版：`public/next/lab.js` 四模型同台对比（基线 / A 只看强弱 / B 加题型难度 / C 加蒙对概率 / D 加遗忘）
- 模拟器：`tools/lab-sim.mjs`（92,265 道真题结构 × 24 个模拟学生 × 400/1500 条作答）
- 参数定档：`K=0.4`、难度权重 `0.7`、`rd0=1.2`、`rdGrow=0.25`、遗忘 `0.05`（组合搜索最优比默认只高 0.11pt，不值得再折腾）
- 实测结论：
  ```
  上限（真有难度+真能力）  0.685
  基线（历史正确率）       0.610
  B/C（难度+蒙对）        0.623   +1.3pt
  真难度（如果难度字段准）  0.640   +3.0pt
  ```

### 还没做
- **进度层**：ZPD 选题、评价口径、分题型能力、θ 接正式版
- **被数据卡住**：难度字段全是假 5（粉笔接口不下发，66 个字段键里没有任何正确率），题级难度只能靠跨用户校准 → 要后端
- **已被否掉**：层级收缩（模拟 0.570 < 单层 0.623）、深度知识追踪（数据量差 3 个数量级）、个人 FSRS 权重拟合（会过拟合）

## 四、体验与工程（P2 清单）

- `android:allowBackup="true"` → 系统备份会带走 AI Key 与答题记录，建议 `false` 或加 backup rules
- `android:usesCleartextTraffic="true"`
- `CAMERA` 权限申请了但 Java 侧无任何相机调用（`MainActivity`/`Bridge` 无 takePicture）
- 双 Activity 均 `screenOrientation="portrait"`
- 4 处横向溢出 7px：`.profile-chip` 106/95、`.training-foot` 355/348、`.opt-row` 350/343、`.switch` 50/42
- 小点击区：字号 chip `39×40`（建议 ≥44）、`.switch` `44×26`
- `public/next/app.js` 已 5,000 行单文件、52 处 `innerHTML`；`catch { toast() }` 会把异常吞成「空列表」（错题本那次就是）
- service worker 在 WebView 必然注册失败（控制台唯一告警）
